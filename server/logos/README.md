# Application logos

Put logo images here (PNG / SVG / JPG / WEBP). Name each file after the application, exactly as it appears in IT Manager — case, spaces and punctuation don't matter:

    SAP.png
    Microsoft 365.svg
    Tally TS Client.png
    SmartDesk.png      (or SMARTDESK.png — the app code works too)

IT Manager checks this folder on start and every minute; a new or replaced file shows on the cards straight away. Files here always win over logos fetched from the internet.
